### 코드 하이라이팅 문제 해결

이전에 적용했던 코드 하이라이팅이 일부 환경에서 제대로 동작하지 않는 문제가 있었다.
확인해보니, `bash`로 작성된 한 줄 코드 블록이 정상적으로 인식되지 않는 문제였다.

원인을 파악하는 과정에서 기존에 사용하던 `rehype-highlight`는
한 줄 명령어의 경우 토큰을 거의 생성하지 않아 하이라이팅이 적용되지 않는다는 점을 확인했다.

이를 해결하기 위해 `shiki` 기반 하이라이터인 `rehype-pretty-code`로 교체했다.
그 결과, 한 줄 명령어도 정상적으로 인식되며 하이라이팅이 안정적으로 적용되었다.

---

### 코드 블록 복사 기능 추가

코드 가독성을 개선한 이후, 사용자 편의성을 높이기 위해 코드 블록 복사 기능을 추가했다.

MDX의 `pre` 태그를 커스텀 컴포넌트로 감싸는 방식으로 구현했으며, 다음과 같은 요소를 포함했다.

- 좌측 상단: 코드 언어 표시
- 우측 상단: 코드 복사 버튼

복사 기능은 `navigator.clipboard.writeText` API를 활용해 구현했고,
버튼 클릭 시 코드가 클립보드에 복사되며 toast 메시지로 피드백을 제공하도록 했다.

UI 요소가 코드와 겹치지 않도록 위치를 분리해 배치한 점도 함께 신경 쓴 부분이다.

---

### 메인 화면 검색 기능 추가

메인 페이지에는 게시글 검색 기능을 추가했다.

`input`을 기반으로 검색어를 상태로 관리하고, 입력값이 변경될 때마다
해당 값을 기준으로 게시글 목록을 필터링하도록 구현했다.

검색은 게시글 제목 기준 부분 일치로 동작하도록 구성했으며:

- 서버: 제목 기반 검색이 가능하도록 API 수정
- 클라이언트: 검색어 변경 시 API 호출 후 결과 렌더링

또한 검색 결과가 없는 경우에는 안내 메시지를 표시해 사용자 경험을 보완했다.

---

## 기타 개선 사항

### 무한 스크롤 메시지 개선

모든 데이터를 불러왔다는 메시지가 초기 렌더링 시점에도 노출되는 문제가 있었다.
이를 실제로 데이터 로딩이 끝난 경우에만 표시되도록 수정했다.

### 배경 그라데이션 문제 해결

게시글 수가 많아질수록 배경 그라데이션이 비정상적으로 늘어나는 문제가 발생했다.
원인은 `%` 기반 `radial-gradient`였고, 이를 고정 `px` 값으로 변경해 페이지 길이에 영향을 받지 않도록 수정했다.
