오늘은 본격적으로 개발을 시작하기에 앞서, **AGENTS.md** 설정부터 진행했다.

`AGENTS.md`는 해당 프로젝트에서 AI 에이전트가 어떻게 행동해야 하는지 정의하는 문서이다.
쉽게 말해, 사람이 프로젝트를 이해하기 위해 `README.md`가 있다면,
`AGENTS.md`는 AI를 위한 README.md라고 보면 된다.

이 문서에는 다음과 같은 내용을 정리한다.
- 이 프로젝트는 무엇을 하는지
- 어떤 폴더와 파일이 중요한디
- 코드 작성 방식 (컨벤션, 스타일 등)
- 테스트 실행 방법
- 수정하면 안 되는 영역
- PR 및 커밋 메시지 규칙

즉, AI가 프로젝트를 수정하거나 코드를 작성할 때
임의로 추측하지 않고, 정해진 규칙에 맞게 작업하도록 돕는 가이드 문서라고 할 수 있다.

___

오늘은 이 `AGENTS.md`를 작성하는 데 대부분의 시간을 사용했다.
생각보다 고려해야 할 부분이 많아서, 프로젝트의 방향성을 다시 한 번 정리하는 시간이기도 했다.

또한 블로그 개발을 위한 프로젝트 기본 구조를 세팅하고, `GitHub Repository`와 연동까지 완료했다.

디자인의 경우에는 `ChatGPT`의 도움을 받아 기본적인 레이아웃을 구성한 뒤,
내가 원하는 방향에 맞게 일부 커스터마이징을 진행헀다.

___

아직은 시작 단계이지만, 프로젝트의 기준과 구조를 먼저 잡아둔 만큼
앞으로의 개발이 훨씬 수월해질 것 같다.
