## 코드 하이라이팅 문제 해결

이전에 적용했던 코드 하이라이팅이 제대로 동작하지 않는 문제가 있었다.
확인해보니, `bash`로 작성된 **한 줄 코드 블록이 제대로 인식되지 않는 문제**였다.

예시를 위해 한 줄짜리 bash 코드 블록을 추가했는데, 이 부분에 하이라이팅이 적용되지 않았다.

원인을 파악하기 위해 Codex와 함께 확인해본 결과,
기존에 사용하던 `rehype-highlight`는 한 줄 명령어의 경우 토큰을 거의 생성하지 않아 하이라이팅이 적용되지 않는다는 것을 알게 되었다.

이 문제를 해결하기 위해 `shiki` 기반 하이라이터인 `rehype-pretty-code`로 라이브러리를 변경했다.

그 결과, 한 줄 명령어도 정상적으로 인식되며 하이라이팅이 잘 적용되는 것을 확인할 수 있었다.

## 코드 블록 복사 기능 추가

코드 하이라이팅을 적용한 이후, 사용자 편의성을 높이기 위해 **코드 블록 복사 기능**을 추가했다.

MDX의 `pre` 태그를 커스텀 컴포넌트로 감싸 렌더링하는 방식으로 구현했으며, 다음과 같은 기능을 포함했다.

- 좌측 상단: 코드 블록의 언어 표시
- 우측 상단: 코드 복사 버튼

UI 요소가 코드와 겹치지 않도록 각각 좌우 상단에 배치했다.

복사 기능은 `navigator.clipboard.writeText` API를 사용했으며,
버튼 클릭 시 해당 코드가 클립보드에 복사되고, toast 메시지를 통해 사용자에게 피드백을 제공하도록 구현했다.

## 메인 화면 검색 기능 추가

메인 화면에서 게시글을 검색할 수 있는 기능을 추가했다.

먼저 `input` 태그를 활용해 검색창을 구현하고, 입력값을 상태로 관리하도록 했다.
사용자가 검색어를 입력할 때마다 해당 값을 기반으로 게시글 목록을 필터링한다.

검색은 **게시글 제목 기준 부분 일치**로 동작하도록 구현했으며:

- 서버: 제목 기준 검색이 가능하도록 API 수정
- 클라이언트: 검색어 변경 시 API 호출 → 결과 렌더링

또한 검색 결과가 없는 경우에는
“검색 결과가 없습니다”라는 메시지를 표시하도록 처리했다.

이 기능을 통해 게시글이 많아지더라도 원하는 글을 쉽게 찾을 수 있게 되었다.

## 기타 개선 사항

### 무한 스크롤 메시지 개선

기존에는 모든 데이터를 불러왔다는 메시지가 초기 렌더링 시에도 보이는 문제가 있었다.
이를 **무한 스크롤이 실제로 종료된 경우에만 표시되도록 수정**했다.

### 배경 그라데이션 문제 해결

게시글 수가 많아질수록 배경의 그라데이션이 비정상적으로 늘어나는 문제가 있었다.

원인은 `%` 기반 `radial-gradient`였고,
이를 **고정된 `px` 값으로 변경**하여 페이지 길이에 영향을 받지 않도록 수정했다.
