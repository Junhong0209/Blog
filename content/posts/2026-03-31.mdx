## MDX 파일 생성 자동화

먼저, 블로그 글을 작성할 때마다 `.mdx` 파일을 직접 생성하는 과정이 꽤 번거롭게 느껴졌다.  
그래서 **명령어 한 줄로 템플릿 기반 MDX 파일을 생성하는 npm 스크립트**를 추가했다.

```bash
npm run new:post -- my-new-post
```

명령어를 실행하면 입력한 문자열을 안전한 slug로 변환한 뒤,  
`content/posts/my-new-post.mdx` 파일을 자동으로 생성해준다.

전체 동작 흐름은 다음과 같다.

1. 입력값 확인
2. slug 정규화
3. 저장 경로 계산
4. 날짜 생성
5. 기본 제목 생성
6. MDX 템플릿 구성
7. 폴더 생성 및 중복 방지
8. 파일 생성

단순하지만, 반복 작업을 줄여주는 꽤 만족스러운 자동화였다.

---

## 무한 스크롤 구현

다음으로는 메인 화면에 **블로그 글 무한 스크롤 기능**을 추가했다.

지금 당장은 게시글 수가 많지 않지만,  
앞으로 글이 쌓일 것을 고려하면 미리 구현해두는 것이 좋겠다고 판단했다.

구현 방식은 다음과 같다.

- 초기 게시글은 **서버 컴포넌트**에서 렌더링
- 이후 데이터는 **클라이언트 컴포넌트**에서 처리
- `IntersectionObserver`를 활용해 다음 페이지 자동 로드

또한, 기능 테스트를 위해 **목업 데이터를 생성하는 스크립트**도 함께 추가했다.  
덕분에 실제 데이터가 많지 않은 상황에서도 자연스럽게 동작을 검증할 수 있었다.

## 코드 하이라이팅 적용

마지막으로, MDX의 코드 블록에 하이라이팅이 적용되지 않는 문제가 있어 이를 개선했다.

`rehype` 플러그인을 추가하여 비교적 간단하게 적용할 수 있었고,  
덕분에 코드 가독성이 훨씬 좋아졌다.

## 느낀점

예전에는 이런 기능들을 하나하나 구현하는 데 꽤 오랜 시간이 걸렸던 기억이 있다.  
하지만 지금은 코딩 에이전트와 대화를 하면서, 원하는 기능을 훨씬 빠르게 구현할 수 있게 된 것 같다.

앞으로도 이런 흐름을 잘 활용해서, 꾸준히 개발하고 기록을 쌓아가야겠다.
