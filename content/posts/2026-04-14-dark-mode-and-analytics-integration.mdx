오늘은 블로그를 한 단계 더 발전시켜, **실제 서비스에 가까운 완성도를 갖추는 작업**을 진행했다.  
테마 전환 기능과 분석 도구 연동, 그리고 배포 과정에서 발생한 문제들을 해결하는 데 집중했다.

___

### 다크 모드 및 테마 시스템 구축

먼저 라이트/다크 모드를 지원하는 테마 시스템을 구현했다.

- 테마 토큰을 light/dark로 분리
- 헤더에 `ThemeToggle` 컴포넌트 추가
- 사용자 선택값을 `localStorage`에 저장해 유지

단순히 테마를 나누는 것에서 끝나지 않고, 전체 UI 요소에 일관된 스타일이 적용되도록 구조를 정리했다.

___

### 댓글(giscus) 테마 동기화

댓글 시스템인 giscus의 테마도 블로그 테마와 동기화되도록 설정했다.

- 라이트 모드 -> `noborder_light`
- 다크 모드 -> `noborder_dark`

테마 변경 시 함께 변경되도록 동기화하여, 사용자 경험의 일관성을 유지할 수 있도록 개선했다.

___

### 테마 관련 Hydration 이슈 해결

테마를 적용하는 과정에서 hydration 관련 오류가 발생했다.

- layout 초기 테마 스크립트 처리 방식 개선
- `ThemeToggle` 렌더 mismatch 문제 수정

초기 렌더링과 클라이언트 상태 간의 불일치를 줄이면서, 안정적으로 테마가 적용되도록 구조를 보완했다.

___

### 분석 도구(GA4) 연동

블로그 운영을 위한 데이터 수집 기반도 구축했다.

- GA4 스크립트 추가 (환경변수 기반)
- 페이지뷰 트래킹 설정
- 외부 링크 클릭 이벤트
- 검색 이벤트
- 포스트 조회 이벤트

분석 관련 로직은 별도 모듈로 분리해 관리하도록 구성했다.

관련 파일:
- `shared/lib/analytics.ts`
- `components/analytics/AnalyticsTracker.tsx`
- `features/blog/ui/PostViewAnalytics.tsx`

또한 `AnalyticsTracker`를 `Suspense`로 감싸 prerender 에러를 해결했다.

___

### Search Console 연동

검색 엔진 등록을 위해 Search Console 검증도 함께 진행했다.

- `GOOGLE_SITE_VERIFICATION` 환경변수 기반
- 메타 태그 자동 주입 방식으로 구성

SEO 설정과 함께 실제 검색 노출을 위한 기반을 완성했다.

___

### 배포 이슈 해결 및 안정화

배포 과정에서 발생한 문제도 함께 해결했다.

- `next-mdx-remote`를 6.0.0으로 업그레이드하여 보안 차단 이슈 해결
- dev 환경에서 검증 후 main 브랜치 반영
- 최종 프로덕션 배포 상태 확인

현재는 `blog-junhong.vercel.app` 도메인에서 정상적으로 접근 가능한 상태다.

___

### 마무리

이번 작업을 통해 블로그는 단순한 프로젝트를 넘어, 실제 운영 가능한 서비스에 가까운 상태로 한 단계 더 발전한 것 같다.  
특히 테마 시스템과 웹 분석을 구축하면서, 앞으로는 사용자 데이터를 기반으로 개선해 나갈 수 있는 기반이 마련되었다.  
다음 단계에서는 성능 최적화와 UI 디테일 개선을 중심으로, 완성도를 더욱 높여갈 계획이다.
