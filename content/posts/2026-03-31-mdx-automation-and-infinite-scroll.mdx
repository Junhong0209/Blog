오늘은 중간중간 `AGENTS.md`를 수정해가며, 본격적인 기능 개발을 진행했다.

### MDX 파일 생성 자동화

블로그 글을 작성할 때마다 `.mdx` 파일을 직접 생성하는 과정이 번거롭게 느껴졌다.
반복 작업을 줄이기 위해 **명령어 한 줄로 템플릿 기반 MDX 파일을 생성하는 npm 스크립트**를 추가했다.

```bash
npm run new:post -- my-new-post
```

명령어를 실행하면 입력한 문자열을 slug로 변환하고,
`content/posts/my-new-post.mdx` 파일을 자동으로 생성하도록 구성했다.

전체 동작 흐름은 다음과 같다.

1. 입력값 검증
2. slug 정규화
3. 저장 경로 계산
4. 날짜 생성
5. 기본 제목 생성
6. MDX 템플릿 구성
7. 폴더 생성 및 중복 방지
8. 파일 생성

단순한 스크립트지만, 반복적인 작업을 줄여준다는 점에서 만족도가 높았다.

---

### 무한 스크롤 구현

메인 페이지에는 블로그 글 무한 스크롤 기능을 추가했다.

현재 게시글 수는 많지 않지만,
앞으로 데이터가 쌓일 것을 고려해 미리 구현해두는 것이 좋겠다고 판단했다.

구현은 다음과 같은 구조로 진행했다.

- 초기 데이터는 서버 컴포넌트에서 렌더링
- 이후 데이터는 클라이언트 컴포넌트에서 처리
- `IntersectionObserver`를 활용해 스크롤 시 다음 페이지 자동 로드

또한 기능 테스트를 위해 목업 데이터 생성 스크립트를 함께 추가했다.
덕분에 실제 데이터가 적은 상황에서도 자연스럽게 동작을 검증할 수 있었다.

### 코드 하이라이팅 적용

MDX 코드 블록에 하이라이팅이 적용되지 않는 문제가 있어 이를 개선했다.

`rehype` 플러그인을 추가해 비교적 간단하게 적용할 수 있었고,
그 결과 코드 가독성이 눈에 띄게 좋아졌다.

---

### 느낀 점

이전에는 이런 기능들을 하나씩 구현하는 데 많은 시간이 필요했던 기억이 있다.
하지만 지금은 코딩 에이전트와의 협업을 통해, 필요한 기능을 훨씬 빠르게 구현할 수 있게 되었다.

물론 모든 것을 자동화에 의존하기보다는,
동작 원리를 이해하고 필요한 부분을 직접 다듬는 과정이 여전히 중요하다고 느꼈다.

앞으로도 이런 흐름을 잘 활용해, 꾸준히 개발하고 기록을 쌓아갈 계획이다.
