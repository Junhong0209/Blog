오늘은 본격적인 기능 개발에 들어가기 전, 프로젝트의 기준을 잡기 위해 **AGENTS.md** 설정부터 진행했다.

`AGENTS.md`는 AI 에이전트가 해당 프로젝트에서 어떻게 행동해야 하는지를 정의하는 문서다.
사람을 위한 README.md가 있다면, `AGENTS.md`는 AI를 위한 가이드 문서라고 볼 수 있다.

이 문서에는 다음과 같은 기준들을 정리했다.

- 프로젝트의 목적과 구조
- 주요 디렉토리 및 파일 역할
- 코드 작성 방식 (컨벤션, 스타일)
- 테스트 실행 방법
- 수정하면 안 되는 영역
- PR 및 커밋 메시지 규칙

이처럼 명확한 기준을 미리 정의해두면, AI가 코드를 생성하거나 수정할 때 불필요한 추측을 줄이고 일관된 결과를 얻을 수 있다.

오늘은 대부분의 시간을 AGENTS.md를 작성하는 데 사용했다.
단순히 문서를 정리하는 작업이었지만, 오히려 프로젝트의 방향성과 기준을 다시 한 번 정리하는 계기가 되었다.

이와 함께 블로그 개발을 위한 기본 프로젝트 구조를 세팅하고, GitHub Repository 연동까지 마무리했다.

디자인은 ChatGPT의 도움을 받아 기본 레이아웃을 빠르게 구성한 뒤, 원하는 방향에 맞게 일부를 커스터마이징했다.
아직 세부적인 부분은 다듬어야 하지만, 전체적인 틀은 어느 정도 갖춰진 상태다.

아직은 시작 단계이지만, 기준과 구조를 먼저 잡아둔 만큼
앞으로의 개발 과정에서 시행착오를 줄일 수 있을 것이라 기대한다.
