# junhong.dev

Personal developer blog built with Next.js App Router, TypeScript, Vanilla Extract, and MDX.

## New Post

```bash
npm run new:post -- my-new-post
```

This creates `content/posts/my-new-post.mdx` with the default frontmatter template.

## Stack

- Next.js
- TypeScript
- Vanilla Extract
- MDX

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```
